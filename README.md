# Maverick Skills

A personal collection of reusable AI skills, templates, examples, and workflow conventions.

## Structure

- `skills/` — installable or reusable skills
- `templates/` — reusable structures and prompt templates
- `examples/` — examples showing how skills are intended to be used
- `docs/` — repository-level design notes and conventions

## Skills

### AI Infra Learning Note

`skills/ai-infra-learning-note`

A learning-oriented technical writing skill for AI infrastructure topics. It organizes material by cognitive dependency rather than by flat topic coverage, building from motivation and mental models toward mechanisms, implementation, trade-offs, and references.

## Philosophy

Optimize for understanding, not completeness.

A concept should appear when the reader needs it, not merely because it is related.
